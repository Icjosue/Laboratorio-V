## Descripción del Proyecto
Este repositorio contiene la implementación de 10 APIs REST desarrolladas con **Java 21** y **Spring Boot**. Cada API incluye el conjunto completo de operaciones CRUD utilizando los verbos HTTP estándar (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`).

---
